# The Economics of Viable Continuation (draft skeleton)

Long graduate textbook by Flyxion, Independent Researcher. October 2026.

- `main.tex`, `preamble.tex`, `refs.bib`, `Makefile`: build (`make book`, `make check`).
- `frontmatter/`: preface, reading paths, notation, the housing case, the proof programme (P01 to P29).
- `parts/`: twelve parts, 60 chapter stubs.
- `appendices/`: prerequisites, companion description, framework concordance.
- `companion/`: finite-state Python checks, tests, recorded output.
- `docs/`: editorial rules, housing specification, proof status, per-chapter briefs (`chapter_briefs/`), prompts, roadmap, provenance.
- `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`: instructions for AI assistants. Start with `AGENTS.md`.
- `NOTES.md`: open decisions. `solutions/`: worked solutions (empty).
- `main.pdf`: last compiled draft.

Nothing is committed. The author makes git commits personally.
